# Contributing

1. Install stable Rust and Python 3.10 or newer.
2. Copy `.env.example` to an ignored local file; never commit data-feed credentials.
3. Run the complete verification block from the README.
4. Add deterministic tests for pricing, risk, configuration, execution, or replay changes.
5. Update the architecture and security documents when an operational control changes.

Pull requests should state the research hypothesis or operational issue, the evidence used, the paper-simulation impact, and manual validation steps. Generated evidence must be rebuilt from its documented source.
